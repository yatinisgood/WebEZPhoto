# EZ Photo

復古相機介面的靜態照片濾鏡工具，以 `reference/layout.PNG` 為版型參考、`assets/P1_small.png`～`assets/P5_small.png` 為五款底片選擇素材。

## 使用

直接以瀏覽器開啟 `index.html`。不需要 npm、建置程序、API key 或後端。

也可以在此目錄執行 `python3 -m http.server 8080`，開啟 http://localhost:8080 。部署時將 `index.html`、`style.css`、`app.js`、`geometry.js`、`film.js` 和 `assets/` 放到任何靜態網站主機即可（全部使用相對路徑，可直接放上 GitHub Pages）。

## 取景與輸出比例

相機的取景螢幕**固定為 3:2**，與照片原始比例、螢幕寬度或裝置無關；螢幕寬度仍隨容器響應式縮放。

- 載入照片時以 Cover 方式填滿 3:2 螢幕：保留原始比例、不拉伸變形，超出部分裁切。
- 頂部「輸出比例」可選 3:2（預設）、4:3、16:9、1:1、3:4、4:5、9:16。
- 輸出裁切框是**能放進 3:2 螢幕的最大同比例矩形**，置中顯示；框外以半透明深色遮罩表示不會輸出，框線與四角標記出實際範圍。例如螢幕 900 × 600 時，4:3 為 800 × 600（符合高度）、16:9 為 900 × 506.25（符合寬度）、1:1 為 600 × 600、3:4 為 450 × 600。
- 切換比例只移動裁切框，不改變相機螢幕比例、機身高度或版型，也會保留目前的縮放與構圖。
- 格線跟隨輸出裁切框，而非整個螢幕。

## 縮放與拖曳

- 預覽螢幕上緣的 ZOOM 滑桿提供 1×～3× 無段數位縮放，拖動即時更新倍率與取景。聚焦滑桿後可用方向鍵微調。這組控制與輸出比例互相獨立。
- 1× 即為 Cover 最低倍率，無法再縮小，因此裁切範圍永遠不會出現空白或黑邊。
- 拖曳照片改變構圖（滑鼠與觸控皆可），或聚焦預覽後使用方向鍵；雙擊照片或重設可恢復。非 3:2 的照片在 1× 時也能沿較長的一軸拖曳。
- 裁切框本身固定置中，不可拖曳或旋轉。

- 選擇或拖入 JPG、PNG、WebP，支援透明度。
- Classic Neg、Evergreen、Nocturne、Solara、800 Cine 五種自訂底片風格。
- TINT 綠／洋紅色偏、白平衡、曝光 ±2 EV、格線、按住比較原圖、重設。
- 底片倉旁的銀色快門下載 PNG：輸出範圍與預覽中明亮的裁切框完全一致，比例即所選的輸出比例，不含遮罩、格線或相機外框。
- 匯出依原圖與實際裁切範圍計算解析度，不放大低解析度預覽；長邊最多 4096 px，且不會超過原始像素。螢幕左下角即時顯示實際輸出尺寸。
- 手機與桌面響應式介面，鍵盤操作與狀態提示。

預覽與匯出共用 `geometry.js` 的同一套取景幾何（3:2 螢幕、Cover 計算、裁切框、匯出尺寸），兩者不會產生偏移或比例誤差。

## 底片調色

`film.js` 是預覽與匯出共用的純像素處理模組，依據 `reference/五款底片模擬調色規格.md` 實作：

| 圖片 | 底片 | 配方 |
| --- | --- | --- |
| P1 | Solara · ISO 200 | 柔和 S 曲線、暗部微抬、金暖中高光、選擇性暖色增豔、橄欖綠、柔和藍色與極細顆粒 |
| P2 | Nocturne · ISO 800 | 視覺亮度加權灰階、中高對比、適度局部對比、暗部多尺度顆粒，高光乾淨，極黑處抑制雜訊 |
| P3 | 800 Cine · ISO 800 | 冷青陰影、暖色光源、收斂飽和度、暗部顆粒，以及強光周圍的局部紅橘 Halation |
| P4 | Evergreen · ISO 100 | 清晰 S 曲線、選擇性綠藍增豔、膚色保護與幾乎不可見的細顆粒 |
| P5 | Classic Neg · ISO 400 | 較紮實的暗部、冷青陰影／奶油暖高光、沉穩綠藍磚紅色與細微彩色顆粒 |

WB、TINT 與 EV 在底片曲線前處理，EV 使用線性光運算。TINT 依參考截圖（±10 為滿檔）設計：在線性光中沿綠↔洋紅軸（G 降、R 升）並於洋紅側補藍，保持亮度不變；中間調與暗部全額偏移，高光逐步回收，讓白色鍵盤不被染色。黑白款的 WB／TINT 會影響轉換後的灰階，不會把影像染色。膚色保護使用柔和的色相／飽和度權重，是近似選色而非人臉辨識。

局部對比與光暈使用全照片、長邊最多 640 px 的空間圖，預覽與匯出共用並快取；光暈透過平滑高光遮罩、周圍亮度差異及雙尺度高斯擴散形成，減少白衣、雲層等大片亮面被染紅。極微小光源可能因縮圖而減弱。顆粒以原圖正規化座標固定種子取樣，縮放、裁切與重新繪製時不會隨機跳動；不同解析度的重採樣仍可能有微小像素差異。透明像素不發光，輸出 alpha 保持不變。所有效果只在本機執行。

## 測試

`tests/geometry.test.js` 是無相依套件的幾何邏輯測試，可用任一 JS 執行環境執行：

```
node tests/geometry.test.js
node tests/film.test.js
jsc film.js tests/film.test.js
jsc geometry.js tests/geometry.test.js        # macOS JavaScriptCore
```

`tests/film.test.js` 包含 12 項調色檢查：灰階、固定顆粒、亮度加權、跨裁切／解析度座標、透明度、局部光暈、色彩分離、膚色、手動調整及曲線過渡。實際照片驗證素材與步驟見 `tests/film-review.md`。

也可在瀏覽器中依序載入 `geometry.js` 與 `tests/geometry.test.js`，結果輸出於主控台。

所有影像解碼、像素處理與輸出都在瀏覽器中進行；無網路請求、分析追蹤或本機持久化。內建風景是 Canvas 繪製的示範圖。

單檔上限 50 MB、6,000 萬像素；HEIC 和 RAW 需先轉為支援格式。濾鏡是參考底片視覺概念的自訂調色，並非原廠 LUT 或精確底片模擬。預覽螢幕緩衝區固定 1080 × 720、來源代理圖長邊最多 1600 px，僅用於顯示；匯出一律取用原始解析度。五款底片各自使用完整配方，黑白款不混入原圖色彩；TINT 以 0 為中性，負值偏綠、正值偏洋紅。輸出不保留原檔 EXIF。大型照片在效能較低的裝置可能需要稍候。

機頂兩顆旋鈕／按鈕為純裝飾，不可點擊，也不進入鍵盤焦點。銀色快門在未載入照片時會開啟選檔，載入後下載 PNG；匯出期間暫時停用以避免重複下載。
