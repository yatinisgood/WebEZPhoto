# EZ Photo

復古相機介面的靜態照片濾鏡工具，以 `reference/layout.PNG` 為版型參考、`reference/5style.png` 為五款底片選擇素材。

## 使用

直接以瀏覽器開啟 `index.html`。不需要 npm、建置程序、API key 或後端。

也可以在此目錄執行 `python3 -m http.server 8080`，開啟 http://localhost:8080 。部署時將 `index.html`、`style.css`、`app.js` 和 `assets/` 放到任何靜態網站主機即可。

## 功能

- 模擬焦距選擇：28 / 40 / 56 / 85 mm 對應 1 / 1.4 / 2 / 3 倍數位縮放，非真實光學焦距。左上旋鈕可循環切換。
- 放大後拖曳照片（觸控亦可）或聚焦預覽後使用方向鍵取景；雙擊照片或重設可恢復。下載依相同裁切範圍輸出，維持原照片比例，不額外放大像素。

- 選擇或拖入 JPG、PNG、WebP，支援透明度。
- Classic Neg、Chrome、Mono、Max、800 Cine 五種自訂底片風格。
- TINT 綠／洋紅色偏、白平衡、曝光 ±2 EV、格線、按住比較原圖、重設。
- 頂部快門下載 PNG；維持比例，長邊最多 4096 px。預覽長邊最多 1600 px。
- 手機與桌面響應式介面，鍵盤操作與狀態提示。

所有影像解碼、像素處理與輸出都在瀏覽器中進行；無網路請求、分析追蹤或本機持久化。內建風景是 Canvas 繪製的示範圖。

單檔上限 50 MB、6,000 萬像素；HEIC 和 RAW 需先轉為支援格式。濾鏡是參考底片視覺概念的自訂調色，並非原廠 LUT 或精確底片模擬。濾鏡混合強度固定為 80%，延續原預設外觀；TINT 以 0 為中性，負值偏綠、正值偏洋紅。輸出不保留原檔 EXIF。大型照片在效能較低的裝置可能需要稍候。
